# AGENTS.md — инструкция для любого ИИ-агента в этом репозитории

Это репозиторий YouTube-канала **«Science History»**: научно-популярные ролики о **научной истории** на русском
языке — археологические раскопки и находки, древние рукописи и книги, история цивилизаций, история религий
(как исторического и культурного явления). Подача — спокойная документалистика: реальные артефакты из
музеев, карты, хронологии, реконструкции с пометками. **Видео собираются кодом** на
[Remotion](https://www.remotion.dev) (React → MP4).

> Это отдельный проект. Ролики о космосе — в `bizonvibe/Kosmos`, о животных — в `bizonvibe/Wildlife`. Не смешивать.

Прочитай этот файл целиком, затем документы из `docs/`. Не начинай делать ролик,
пока не понял формат сдачи (`docs/06-delivery.md`) и правила монтажа (`docs/07-shot-rules.md`).

---

## Что от тебя обычно хотят

| Запрос | Что делаешь | Где эталон |
|---|---|---|
| «Сделай видео про <находку/эпоху/рукопись>» | Сценарий → раскадровка по планам 4 с → конфиг по шаблону → рендер + QC | `video/src/videos/_template/` |
| «Напиши сценарий» | Файл по шаблону `templates/script.template.md` в `scripts/<тема>/` | — |
| «Сделай раскадровку» | Файл по шаблону `templates/storyboard.template.md` (строка = план 3–4 с) | — |
| «Найди материалы» | Источники и лицензии строго по `docs/04-assets-and-licenses.md`, запись в манифест | `templates/footage.manifest.template.json` |

Результат **всегда** сдаётся в формате из `docs/06-delivery.md`: MP4 + отчёт + титры источников.

## Железные правила (нарушать нельзя)

1. **Факты и даты.** Каждая дата, цифра, атрибуция и перевод — из научного источника: музейная карточка
   предмета, научная публикация, академическая энциклопедия, официальный сайт раскопок/музея. Указывай
   датировку так, как в источнике (диапазоны, «около», «до н. э.»). Спорное — с маркерами
   «по одной из версий», «учёные спорят», «традиция приписывает…».
2. **Религия — нейтрально.** Религии показываем как историко-культурное явление: что говорят источники и
   археология, что — традиция и вера, без оценок, насмешек и проповеди. Священные тексты цитируем по
   признанным переводам с указанием перевода. Никаких оскорблений чувств верующих и сенсационных «разоблачений».
3. **Без псевдоистории.** Никаких «древних пришельцев», «запретной археологии», «скрытых знаний» как фактов.
   Если тема популярна — показываем, что говорит наука, и почему версия не принята.
4. **Лицензии.** Только материалы с понятной лицензией из `docs/04-assets-and-licenses.md`.
   Каждый внешний файл → запись в `footage.manifest.json` ролика и подпись в кадре (`credit`: музей, номер предмета).
   Никаких кусков фильмов/сериалов/чужих YouTube-роликов, логотипов телеканалов.
5. **Реконструкции помечаются.** Реконструкция, ИИ-иллюстрация, «как могло выглядеть» — с меткой в кадре
   («Реконструкция», «Иллюстрация · ИИ»). Реальный артефакт — с названием, датировкой и музеем.
6. **Детерминизм рендера.** Любая анимация зависит только от `useCurrentFrame()`. Запрещены `Math.random()` без сида,
   CSS-анимации/transition, таймеры, `useFrame()` из R3F. Подробнее — `docs/03-remotion-mechanics.md`.
7. **Ничего не грузим из сети во время рендера.** Шрифты, футаж, изображения, звук — локально в `video/public/`.
8. **Стиль канала** — только из `docs/02-style-guide.md`. Не изобретай новый стиль без запроса.
9. **Проверка перед рендером.** `npx tsc -p .` без ошибок → контрольные кадры `scripts/stills.sh` →
   посмотреть их глазами → только потом полный рендер.
10. **Сдача.** MP4 1920×1080, 30 fps, H.264, AAC 48 кГц, −14 LUFS (делает `scripts/render.sh`) +
    отчёт по шаблону `templates/delivery-report.template.md` + титры для описания YouTube.
11. **Git.** Код, конфиги, манифесты, сценарии — коммитим. Готовые MP4 и тяжёлые исходники (>50 МБ на ролик) — нет
    (`video/out/` в .gitignore); MP4 отдаём пользователю файлом.
12. **Если что-то заблокировано** (сеть, ключ API, лицензия) — не подменяй молча заглушками и не выдумывай.
    Скажи, что нужно, и предложи вариант. Заглушки допустимы только явно помеченные (`credit: 'ЗАГЛУШКА…'`).
13. **Монтаж по `docs/07-shot-rules.md`:** кадр меняется не реже раза в **4 секунды**, любые два плана похожи
    не более чем на **90 %** (SSIM), на каждом плане моушн-графика или инфографика. Проверяет `scripts/qc_shots.py`
    (встроен в `render.sh`). Не прошёл QC — не сдаём.
14. **Порядок поиска материалов:** (1) стоковое **видео** (Pexels, Pixabay, Wikimedia) → (2) если видео нет —
    **изображения**: музеи открытого доступа (CC0), библиотеки и архивы, Wikimedia/Openverse, стоки →
    (3) Google Картинки — только вручную с фильтром Creative Commons и проверкой лицензии на исходной странице →
    (4) **собственная генерация**: карты, хронологии, схемы, 3D, ИИ-иллюстрации с пометкой «Иллюстрация · ИИ».
    Неподвижные изображения всегда «оживляем»: наезд, панорама, параллакс, маски, подсветка деталей.
15. **Киноязык по `docs/09-cinecraft.md`:** у каждого плана строка камеры (движение, секунды, кривая, цель),
    крючок — недосказанность, один поворот, финал держит своё время; титры проходят `scripts/words_check.py`;
    перед финальным рендером — шесть вопросов «жюри» по контрольным кадрам.
