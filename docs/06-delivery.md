# 06. Формат сдачи видео

Это то, **в каком виде пользователь ждёт результат**. Сдача без любого из пунктов — не сдача.

## 1. Видеофайл

| Параметр | Значение |
|---|---|
| Контейнер / кодек | MP4, H.264 (yuv420p), CRF 18, `+faststart` |
| Разрешение / fps | 1920×1080, 30 fps (Shorts по запросу: 1080×1920) |
| Звук | AAC 192 кбит/с, 48 кГц, стерео, **−14 LUFS**, true peak ≤ −1 dBTP |
| Имя | `video/out/<slug>.mp4` (латиница, дефисы), например `snow-leopard.mp4` |
| Длительность | как в задаче, допуск ±0,5 с |

Делается одной командой: `video/scripts/render.sh <Composition> <slug>`.
MP4 **не коммитится** в git — отправляется пользователю файлом.

## 2. Что коммитится в репозиторий
- Код ролика: `video/src/videos/<slug>/` (+ регистрация в `video/src/Root.tsx`).
- `video/src/videos/<slug>/footage.manifest.json` — все внешние файлы.
- `video/src/videos/<slug>/CREDITS.md` — титры для описания YouTube (шаблон `templates/credits.template.md`).
- Сценарий и раскадровка: `scripts/<тема>/<slug>.md`, `scripts/<тема>/<slug>.storyboard.md`.
- Небольшие ассеты (< 50 МБ суммарно на ролик) — в `video/public/…`; большие — только ссылки в манифесте.

## 3. Отчёт пользователю
В ответе — короткий отчёт по шаблону `templates/delivery-report.template.md`:
таблица сцен с таймкодами, что использовано (футаж/3D/инфографика), источники и лицензии,
что не удалось и почему, что предлагается дальше. Без воды.

## 4. Чек-лист качества (пройти по контрольным кадрам и готовому MP4)
- [ ] **QC монтажа пройден** (`scripts/qc_shots.py`: смена кадра ≤ 4 с, сходство планов ≤ 90 %), отчёт `out/<slug>.qc.json`.
- [ ] Длительность и параметры файла верные (`ffprobe`).
- [ ] Ни один текст не обрезан и не налезает на объект/другой текст; поля 120 px соблюдены.
- [ ] Все цифры совпадают со сценарием/источником; единицы по-русски.
- [ ] Текстуры и футаж реально видны (нет пустых/чёрных кадров, заглушек).
- [ ] Подпись источника (`credit`) видна на каждом внешнем футаже; заглушек `ЗАГЛУШКА` не осталось.
- [ ] Склейки с light leak, нет резких скачков яркости; в конце уход в чёрное.
- [ ] Звук: нет клиппинга, музыка не перекрывает голос, удары совпадают с появлением цифр.
- [ ] `npx tsc -p .` без ошибок, код закоммичен и запушен в рабочую ветку.

## 5. Эталон
Эталон стиля «световой стол» (один предмет, лупа, выноски, 15 планов, QC пройден) — `video/src/videos/hori-gates/`.
